# Security Policy

Please report suspected vulnerabilities privately to the repository owner instead of opening a public issue. Include affected routes or migrations, reproduction steps, impact, and any suggested mitigation.

The current supported version is the latest revision on the default branch. See [`docs/security.md`](docs/security.md) for the implemented trust and authorization model.

Public portfolio credentials, when provisioned, belong only to a disposable Supabase demo project and synthetic tenant. They must never be reused for a production restaurant. Do not include service-role keys, database passwords, JWT secrets, or private keys in a report posted publicly.
